# 🏸 羽球排點與上場管理系統

專為約 **15 人、兩面場（同時 8 人在場上）** 的羽球團設計的網頁排點工具，針對平板與手機置於場邊觸控操作進行優化。系統為純前端單一 HTML 檔案（零後端依賴），支援瀏覽器本機自動存檔，打開即用；載入過一次後，球館沒網路也能使用。

🔗 **線上使用網址**：[https://kevin810402-maker.github.io/badminton/](https://kevin810402-maker.github.io/badminton/)

---

## ✨ 核心功能

### 1. 現場排點流程（前 2 場手動 + 第 3 場起自動）
* **✋ 第 1、2 場手動開場**：考量開打初期常有球友遲到，前 2 場預設進入手動模式，點擊已到場球友填入 A / B 隊槽位，並提供 **`⚖️ 自動分隊（依級別平衡）`** 一鍵配平。
* **🤖 第 3 場起自動運算**：第 2 場開打後自動切換為智慧運算排點，同時保留 **`✋ 臨時改手動`** 開關，隨時因應現場突發狀況；臨時手動會**持續到按下 `🤖 切回自動運算`** 為止。
* **🏃 遲到球友快速報到與即時重算**：主頁直接顯示尚未到場球友列表，點一下即刻報到並**立即重新運算**第 3 場與後續順位（例如從 12 人變 15 人時自動納入新到場人員）。若是今天稍早取消到場又回來，會**還原原本的場數與繳費狀態**，不會從 0 場重新算。
* **✅ 不分場號 & 一鍵下場**：場上僅顯示進行中的 4 人組別卡片，打完點擊 **`✅ 一鍵下場（4人結束）`** 即可同時結算 4 人、累計場次、寫入紀錄並自動補位。
* **🏟️ 兩面場上限**：場上已有 2 組時，「確認上場」按鈕會停用並顯示「2 面場使用中」，避免誤開第 3 場。
* **🔄 彈性微調**：自動模式下點擊任兩位場下或預備球友即可**互換位置**；預備組被手動調整後會標示 **`📌 已手動調整`**，不會被自動重算蓋掉，並在下一組空出時**直接晉升為下一組**（依級別平衡分隊）。支援個別球友切換**暫休／回歸**並即時重算排隊。

### 2. 智慧排點與分隊演算法
系統以 **公平性優先** 搭配 **性別與級別（5–10 級）平衡**：
1. **公平候選池**：優先挑選「上場次數最少（與最低落差 $\le 1$ 場）」且「下場等待最久」的球友。
   * **遲到／暫休回歸者連打限制**：這些人場數較少會被優先排入，但**最多連打 2 場就必須休息**（下場後至少等過 2 次開場才會再被排入），場下卡片會標示 `連打休息`。場數追上其他人後自動回到一般輪轉。若場下可用人數不足 4 人，才會例外讓需休息者上場。
2. **性別組隊優先序**：
   * 第一順位：**4 位女生（女雙）**
   * 第二順位：**4 位男生（男雙）**
   * 第三順位：**2 男 2 女對稱混雙**（強制拆為 `1男1女 vs 1男1女`）
3. **級別平衡（5–10 級）**：
   * 內建 6 種高對比色標（Lv.5 翡翠綠 ～ Lv.10 黑底金字）。
   * 對超過 2 級的極端級距加重懲罰，避免實力過度懸殊。
   * 4 人分隊時自動選出雙方級數總和差值最小的組合。

### 3. 👥 球友名冊與 💰 臨打記帳
* **永久名冊與今日到場分離**：維護常駐球友姓名、性別、級別（5–10 級）與個別臨打費；提供 **`⚡ 隨機生成 15 位球友（10男5女）`** 方便快速測試（名冊已有資料時會先跳出確認視窗，避免誤蓋真實名冊）。
* **臨打費用記帳**：可設定預設臨打費（預設 `$200`）或針對季繳球友設為 `$0`，即時統計**應收總額、已收總額、未繳人數**，一鍵切換 `❌ 未繳` / `✅ 已繳`。
  * 記帳頁修改的金額**只影響今天**，且可「回復上一步」；要改常駐臨打費，請到「👥 球友名冊 → ✏️ 編輯」。

### 4. 📜 場次紀錄、↩️ 30 步復原與 🧪 模擬 10 場
* **場次紀錄與統計**：自動分類統計女雙／男雙／混雙場次、今日個人上場次數排行，並標示每場為 `✋ 手動` 或 `🤖 自動` 及級距區間；附有獨立的 **`🗑️ 清除場次紀錄`** 按鈕。
* **30 步狀態快照復原（Undo）**：幾乎所有關鍵操作（上場、下場、互換、報到、清除紀錄等）皆可一鍵回復上一步。
* **🧪 模擬 10 場（沙盒分頁）**：不影響真實資料，可直接用「10 男 5 女隨機名單」或「目前出席名單」模擬 2 面場輪轉 10 場，產出對戰類型統計、平均級數差、每人上場公平性與「層級兩兩同場次數」報表。

## 💾 資料儲存與備份機制

本系統使用瀏覽器 `localStorage`（鍵值：`badminton_queue_v4`）進行**即時自動存檔**，誤關網頁或重新整理皆不會遺失資料。

* **手動清除選項**（皆附二次確認防誤觸）：
  * `🗑️ 清除場次紀錄`：清空紀錄並歸零今日上場數，保留名冊與記帳。
  * `🔄 重設今日場次`：清空場上組別與紀錄並回到第 1 場手動模式，保留球友名冊。
  * `🗑️ 完全清空所有資料`：徹底清除所有本機資料（含名冊）。
* **JSON 匯出／匯入**：建好固定球友名冊後，建議於「👥 球友名冊」最下方按 **`⬇ 匯出備份 (JSON)`** 留存備份檔，方便換裝置時一鍵還原。
  * 備份檔不含「回復上一步」的紀錄，檔案較小。
  * 匯入後若發現選錯檔案，可按 **`↩️ 回復上一步`** 回到匯入前的狀態。

> **⚠️ 本機存檔使用提醒**：
> 1. 請勿使用無痕／私密瀏覽模式開啟，亦避免從 LINE 內建瀏覽器直接操作。
> 2. 建議固定使用同一台平板與同一款瀏覽器（並加入主畫面），避免 Safari 閒置超過 7 天自動清理網站暫存。

## 📱 平板加入主畫面（當作 App 使用）

* **iPad (Safari)**：開啟網址 → 點擊右上角「分享」圖示 → 選擇 **「加入主畫面」** → 點擊「新增」。
* **Android 平板 (Chrome)**：開啟網址 → 點擊右上角「⋮」選單 → 選擇 **「加到主畫面」**（或「安裝應用程式」）。

> **📶 離線使用**：只要在有網路時打開過一次，之後球館沒網路也能正常開啟與操作（由 `sw.js` 快取網頁，樣式已內嵌在 `index.html`）。有網路時會自動抓最新版。離線時字型會改用系統字型，不影響使用。

## 🚀 部署與更新方式

本專案直接部署於 **GitHub Pages**，儲存庫根目錄結構：

```
index.html            主程式（含內嵌的 Tailwind CSS）
sw.js                 離線快取（Service Worker）
README.md
tools/build-css.js    重新編譯並內嵌 Tailwind CSS
tools/tailwind.config.js
```

1. 至 GitHub 儲存庫的 **Settings → Pages**，將 Branch 設為 `main`（`/ (root)`）並儲存。
2. 日後修改程式碼時，更新 `index.html` 並 Commit / Push，等待約 1–2 分鐘重新整理網頁即可生效。
3. **若有新增或修改 Tailwind class**（例如換顏色、改排版），Commit 前請先在專案根目錄執行：
   ```bash
   node tools/build-css.js
   ```
   這會重新產生 CSS 並寫回 `index.html`（需要 Node.js；第一次執行會自動下載 Tailwind）。只改 JS 邏輯或文字則不需要。

## 🛠️ 技術架構

* **HTML5**（單一檔案架構）
* **Tailwind CSS 3.4**（預先編譯後內嵌於 HTML，不依賴 CDN；響應式平板優先排版）
* **Vanilla JavaScript**（純原生 JS 狀態管理、演算法與渲染）
* **Web Storage API**（`localStorage` 持久化與 JSON 匯出／匯入）
* **Service Worker**（`sw.js` 離線快取）
